# Contributing

PlanPilot is a portfolio project. Contributions and focused bug reports are welcome.

## Prerequisites

- Node.js 18.11 or newer
- MongoDB Community locally, or a MongoDB Atlas connection string

## Local development

Follow the setup steps in [README.md](README.md), including the client and server environment files, database seed, and development commands.

## Changes

- Create a focused branch from `main`.
- Keep changes small, honest, and consistent with the existing code.
- Do not commit secrets or `.env` files.
- Update relevant documentation when behavior changes.
- Run `npm run build` before opening a pull request.

Open a pull request with a short summary, testing notes, and screenshots for visible UI changes.
